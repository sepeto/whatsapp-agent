📋 Descripción del Flujo

Fase 1 - Inicialización: El sistema arranca, conecta con MongoDB y carga la configuración de todos los bots activos. Se inicializan los clientes de WhatsApp Web y se configura la API de OpenAI.
Fase 2 - Recepción: Cuando llega un mensaje de WhatsApp, el sistema verifica si hay un bot disponible y extrae la información del remitente. Se determina si es una conversación nueva o existente.
Fase 3 - Procesamiento IA: Se carga el contexto conversacional (últimos 20 mensajes), se realiza la llamada a OpenAI API con sistema de reintentos, y se procesa la respuesta generada por la IA.
Fase 4 - Ejecución: Se envía la respuesta por WhatsApp, se guarda todo en MongoDB, y se ejecutan acciones adicionales como agendar citas en Google Calendar, actualizar leads en Airtable, y programar recordatorios.
Fase 5 - Monitoreo: Se actualizan las métricas del dashboard, se registran logs sistemáticos, y se envían notificaciones según configuración.
Sistema de Colas: Para manejar múltiples bots concurrentemente, se utiliza un sistema de colas con límite de 3 bots simultáneos, procesamiento por lotes y balance automático de carga.
